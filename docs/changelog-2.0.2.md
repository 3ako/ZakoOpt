# ZakoOpt 2.0.2

**Create (1.21.1 NeoForge only)**
- Train coupling cables and train doors are copied from one drawn piece instead of being redrawn, and skipped when out of view. Up to ~18% more FPS in a scene with 4 long trains (28 carriages); no change without trains.
- Toggles in `zakoopt.json`: `createCouplings`, `createDoors`.

No changes for the other versions and for Fabric on 1.21.1.
