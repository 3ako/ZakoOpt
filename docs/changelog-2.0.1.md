# ZakoOpt 2.0.1

## Русский

**Исправления**
- Вылет «Out of stack space» при отрисовке спавнера с крупным мобом (например, дракона Края) вместе с Sodium. Кэшированные меши больше не выделяются на MemoryStack LWJGL.

---

## English

**Fixes**
- Crash "Out of stack space" when rendering a mob spawner with a large mob (e.g. an ender dragon) with Sodium. Cached meshes are no longer allocated on the LWJGL MemoryStack.
